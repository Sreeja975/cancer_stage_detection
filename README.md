# Breast Cancer Detection & AI TNM Staging

This is a Streamlit-based web application that performs **breast cancer detection** from mammogram images using **ResNet18** and provides **automatic TNM staging**. It also features:

- **Grad-CAM visualization** for interpretability  
- **AI medical voice assistant** for interactive Q&A  
- **Automatic medical report generation** including stage, TNM, Grad-CAM image, and AI responses  

---

## 🛠️ Features

- Binary classification: Benign vs Malignant  
- TNM staging (T, N, M) for malignant cases  
- Grad-CAM heatmap overlay for visualization  
- Voice-to-text input and text-to-speech output  
- Downloadable PDF medical report
